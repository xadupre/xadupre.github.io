models
======

Lists the available mock ONNX test models shipped with the package.
These models are useful for unit testing and offline development.

Usage
-----

.. code-block:: bash

    python -m locodellm models

Example output
--------------

.. code-block:: text

    mock/generate  Mock LLM with hardcoded outputs for two Qwen2.5-Coder prompts.
    mock/tiny      Tiny model with zero weights for fast loading and smoke tests.
