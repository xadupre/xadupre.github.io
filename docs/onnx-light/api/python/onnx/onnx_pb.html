onnx_light.onnx.onnx_pb#

Compatibility shim for onnx.onnx_pb.

Re-exports all protobuf message types from the top-level onnx_light.onnx package so that from onnx_light.onnx.onnx_pb import ModelProto works.

class onnx_light.onnx.onnx_pb.StructTypeProto(*args, **kwargs)#

Describes a struct’s fields and types: a concrete declaration selects array, bit_packing or structure, and each field selects either a value type or a tensor constant. A fixed physical size is an eligibility condition for byte encoding, not a requirement on every struct.
