Shape-inference coverage#

This page reports, for every backend test case tagged "inference" (see onnx_light.onnx.backend.TestCase.tag), the outcome of running the onnx_shapes shape-inference pipeline against the expected intermediate and output shapes recorded by the test author.

For every collected case, the report:

  1. renders the original model — including the expected value_info and output shapes — as a compact text listing via pretty_onnx();

  2. clones the model and strips its ``graph.value_info`` so shape inference cannot just reuse the recorded intermediate shapes;

  3. runs onnx_light.onnx_core.shape_inference.infer_shapes_model() on the stripped clone;

  4. emits a side-by-side table contrasting the expected and the computed shape of every input, intermediate and output value, with the match status colored yes / no.

When shape inference itself raises, the error message is shown instead of the comparison table.

Summary#

Overall pass rate across all "inference"-tagged backend test cases:

<<<

from onnx_light.doc import (
    compute_inference_coverage,
    render_rst_summary,
)

_report = compute_inference_coverage()
print(render_rst_summary(_report))

>>>
