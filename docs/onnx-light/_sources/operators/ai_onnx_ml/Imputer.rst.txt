.. _op_ai_onnx_ml_Imputer:

Imputer
=======

- **Domain**: ``ai.onnx.ml``
- **Since version**: 1

Replaces inputs that equal one value with another, leaving all other elements alone. 
This operator is typically used to replace missing values in situations where they have a canonical
representation, such as -1, 0, NaN, or some extreme value. 
One and only one of imputed_value_floats or imputed_value_int64s should be defined -- floats if the input tensor
holds floats, integers if the input tensor holds integers. The imputed values must all fit within the
width of the tensor element type. One and only one of the replaced_value_float or replaced_value_int64 should be defined,
which one depends on whether floats or integers are being processed. 
The imputed_value attribute length can be 1 element, or it can have one element per input feature. In other words, if the input tensor has the shape [\*,F], then the length of the attribute array may be 1 or F. If it is 1, then it is broadcast along the last dimension and applied to each feature.

**Inputs**

- **X** (*T*): Data to be processed.

**Outputs**

- **Y** (*T*): Imputed output data

**Type Constraints**

- **T**: The input type must be a tensor of a numeric type, either [N,C] or [C]. The output type will be of the same tensor type and shape.
  Allowed types: tensor(double), tensor(float), tensor(int32), tensor(int64).

Examples
--------

**test_cc_imputer_float**

.. code-block:: text

    Node:
      ai.onnx.ml.Imputer(x) -> (y)
      Attributes:
        replaced_value_float = 0.0
        imputed_value_floats = [1.0, 2.0, 3.0]

.. code-block:: text

    Inputs:
      x: shape=(2, 3), dtype=float32
        [[0., 1., 0.],
         [5., 0., 6.]]

    Outputs:
      y: shape=(2, 3), dtype=float32
        [[1., 1., 3.],
         [5., 2., 6.]]

**test_cc_imputer_float_broadcast**

.. code-block:: text

    Node:
      ai.onnx.ml.Imputer(x) -> (y)
      Attributes:
        replaced_value_float = -1.0
        imputed_value_floats = [0.0]

.. code-block:: text

    Inputs:
      x: shape=(4,), dtype=float32
        [-1.,  2., -1.,  4.]

    Outputs:
      y: shape=(4,), dtype=float32
        [0., 2., 0., 4.]

**test_cc_imputer_float_nan**

.. code-block:: text

    Node:
      ai.onnx.ml.Imputer(x) -> (y)
      Attributes:
        replaced_value_float = nan
        imputed_value_floats = [0.0]

.. code-block:: text

    Inputs:
      x: shape=(3,), dtype=float32
        [nan,  2., nan]

    Outputs:
      y: shape=(3,), dtype=float32
        [0., 2., 0.]

**test_cc_imputer_int64**

.. code-block:: text

    Node:
      ai.onnx.ml.Imputer(x) -> (y)
      Attributes:
        replaced_value_int64 = 0
        imputed_value_int64s = [10, 20]

.. code-block:: text

    Inputs:
      x: shape=(3, 2), dtype=int64
        [[0, 0],
         [1, 2],
         [0, 3]]

    Outputs:
      y: shape=(3, 2), dtype=int64
        [[10, 20],
         [ 1,  2],
         [10,  3]]
