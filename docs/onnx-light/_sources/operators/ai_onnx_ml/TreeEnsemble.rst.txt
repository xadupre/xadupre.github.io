.. _op_ai_onnx_ml_TreeEnsemble:

TreeEnsemble
============

- **Domain**: ``ai.onnx.ml``
- **Since version**: 5

Tree Ensemble operator.  Returns the regressed values for each input in a batch.
Inputs have dimensions ``[N, F]`` where ``N`` is the input batch size and ``F`` is the number of input features.
Outputs have dimensions ``[N, num_targets]`` where ``N`` is the batch size and ``num_targets`` is the number of targets, which is a configurable attribute.

The encoding of this attribute is split along interior nodes and the leaves of the trees. Notably, attributes with the prefix ``nodes_*`` are associated with interior nodes, and attributes with the prefix ``leaf_*`` are associated with leaves.
The attributes ``nodes_*`` must all have the same length and encode a sequence of tuples, as defined by taking all the ``nodes_*`` fields at a given position.

All fields prefixed with ``leaf_*`` represent tree leaves, and similarly define tuples of leaves and must have identical length.

This operator can be used to implement both the previous ``TreeEnsembleRegressor`` and ``TreeEnsembleClassifier`` nodes.
The ``TreeEnsembleRegressor`` node maps directly to this node and requires changing how the nodes are represented.
The ``TreeEnsembleClassifier`` node can be implemented by adding a ``ArgMax`` node after this node to determine the top class.
To encode class labels, a ``LabelEncoder`` or ``GatherND`` operator may be used.

**Inputs**

- **X** (*T*): Input of shape [Batch Size, Number of Features]

**Outputs**

- **Y** (*T*): Output of shape [Batch Size, Number of targets]

**Attributes**

- **aggregate_function** (*int*): Defines how to aggregate leaf values within a target.
- **leaf_targetids** (*int[]*): The index of the target that this leaf contributes to.
- **leaf_weights** (*tensor*): The weight for each leaf.
- **membership_values** (*tensor*): Members to test membership of for each set membership node.
- **n_targets** (*int*): The total number of targets.
- **nodes_falseleafs** (*int[]*): 1 if false branch is leaf for each node and 0 if an interior node.
- **nodes_falsenodeids** (*int[]*): If nodes_falseleafs is false at an entry, this represents the position of the false branch node.
- **nodes_featureids** (*int[]*): Feature id for each node.
- **nodes_hitrates** (*tensor*): Popularity of each node, used for performance and may be omitted.
- **nodes_missing_value_tracks_true** (*int[]*): For each node, define whether to follow the true branch in the presence of a NaN input feature.
- **nodes_modes** (*tensor*): The comparison operation performed by the node.
- **nodes_splits** (*tensor*): Thresholds to do the splitting on for each node with mode that is not 'BRANCH_MEMBER'.
- **nodes_trueleafs** (*int[]*): 1 if true branch is leaf for each node and 0 an interior node.
- **nodes_truenodeids** (*int[]*): If nodes_trueleafs is false at an entry, this represents the position of the true branch node.
- **post_transform** (*int*): Indicates the transform to apply to the score.
- **tree_roots** (*int[]*): Index into nodes\* for the root of each tree.

**Type Constraints**

- **T**: The input type must be a tensor of a numeric type.
  Allowed types: tensor(double), tensor(float), tensor(float16).
