Exp - version 6
===============

This page documents version **6** of operator **Exp**. See :doc:`Exp` for the latest version (since version 13).

- **Domain**: ``ai.onnx``
- **Since version**: 6

Computes the Exp value of the input tensor element-wise.

**Inputs**

- **input** (*T*): Input tensor

**Outputs**

- **output** (*T*): The exponential of the input tensor computed element-wise

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
