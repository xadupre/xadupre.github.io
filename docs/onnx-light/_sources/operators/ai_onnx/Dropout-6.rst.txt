Dropout - version 6
===================

This page documents version **6** of operator **Dropout**. See :doc:`Dropout` for the latest version (since version 22).

- **Domain**: ``ai.onnx``
- **Since version**: 6

**Inputs**

- **data** (*T*): The input data as Tensor.

**Outputs**

- **output** (*T*): The output.
- **mask** (*T*): The output mask. If is_test is nonzero, this output is not filled.

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).

-------------------------------------

**SchemaDiff**: ``Dropout`` (domain ``'ai.onnx'``)

* old version: 1
* new version: 6
* breaking: no
