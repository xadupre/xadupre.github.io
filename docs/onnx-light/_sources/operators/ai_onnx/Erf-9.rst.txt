Erf - version 9
===============

This page documents version **9** of operator **Erf**. See :doc:`Erf` for the latest version (since version 13).

- **Domain**: ``ai.onnx``
- **Since version**: 9

Computes the Erf value of the input tensor element-wise.

**Inputs**

- **input** (*T*): Input tensor

**Outputs**

- **output** (*T*): The error function of the input tensor computed element-wise. It has the same shape and type of the input.

**Type Constraints**

- **T**: Constrain input and output types to all numeric tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16), tensor(int16), tensor(int32), tensor(int64), tensor(int8), tensor(uint16), tensor(uint32), tensor(uint64), tensor(uint8).
