Max - version 1
===============

This page documents version **1** of operator **Max**. See :doc:`Max` for the latest version (since version 13).

- **Domain**: ``ai.onnx``
- **Since version**: 1

Element-wise max of each of the input tensors. All inputs and outputs must
have the same shape and data type.

**Inputs**

- **data_0** (*T*): List of tensors for Max.

**Outputs**

- **max** (*T*): Output tensor. Same dimension as inputs.

**Attributes**

- **consumed_inputs** (*int[]*): legacy optimization attribute.

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
