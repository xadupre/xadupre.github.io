Sqrt - version 6
================

This page documents version **6** of operator **Sqrt**. See :doc:`Sqrt` for the latest version (since version 13).

- **Domain**: ``ai.onnx``
- **Since version**: 6

Square root takes one input data (Tensor ) and produces one output data
(Tensor ) where the square root is, y = x^0.5, is applied to
the tensor elementwise. If x is negative, then it will return NaN.

**Inputs**

- **X** (*T*): Input tensor

**Outputs**

- **Y** (*T*): Output tensor

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
