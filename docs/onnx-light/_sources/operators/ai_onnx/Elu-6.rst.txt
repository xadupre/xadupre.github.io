Elu - version 6
===============

This page documents version **6** of operator **Elu**. See :doc:`Elu` for the latest version (since version 22).

- **Domain**: ``ai.onnx``
- **Since version**: 6

Elu takes one input data (Tensor ) and produces one output data
(Tensor ) where the function ``f(x) = alpha * (exp(x) - 1.) for x  = 0``., is applied to the tensor elementwise.

**Inputs**

- **X** (*T*): Input tensor

**Outputs**

- **Y** (*T*): Output tensor

**Attributes**

- **alpha** (*float*): Coefficient of ELU.

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).

Examples
--------

**test_cc_elu**

.. code-block:: text

    Node:
      Elu(X) -> (Y)
      Attributes:
        alpha = 2.0

.. code-block:: text

    Inputs:
      X: shape=(2, 3), dtype=float32
        [[-2. , -1. , -0.5],
         [ 0.5,  1. ,  2. ]]

    Outputs:
      Y: shape=(2, 3), dtype=float32
        [[-1.7293295 , -1.2642411 , -0.78693867],
         [ 0.5       ,  1.        ,  2.        ]]
