Reshape - version 5
===================

This page documents version **5** of operator **Reshape**. See :doc:`Reshape` for the latest version (since version 25).

- **Domain**: ``ai.onnx``
- **Since version**: 5

Reshape the input tensor similar to numpy.reshape.

**Inputs**

- **data** (*T*): An input tensor.
- **shape** (*tensor(int64)*): Specified shape for output.

**Outputs**

- **reshaped** (*T*): Reshaped data.

**Type Constraints**

- **T**: Constrain input and output types to all tensor types.
  Allowed types: tensor(bool), tensor(complex128), tensor(complex64), tensor(double), tensor(float), tensor(float16), tensor(int16), tensor(int32), tensor(int64), tensor(int8), tensor(string), tensor(uint16), tensor(uint32), tensor(uint64), tensor(uint8).
