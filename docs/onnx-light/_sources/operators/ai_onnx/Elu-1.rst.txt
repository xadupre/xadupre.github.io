Elu - version 1
===============

This page documents version **1** of operator **Elu**. See :doc:`Elu` for the latest version (since version 22).

- **Domain**: ``ai.onnx``
- **Since version**: 1

Elu takes one input data (Tensor ) and produces one output data
(Tensor ) where the function ``f(x) = alpha * (exp(x) - 1.) for x  = 0``., is applied to the tensor elementwise.

**Inputs**

- **X** (*T*): Input tensor

**Outputs**

- **Y** (*T*): Output tensor

**Attributes**

- **alpha** (*float*): Coefficient of ELU default to 1.0.

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
