Ceil - version 6
================

This page documents version **6** of operator **Ceil**. See :doc:`Ceil` for the latest version (since version 13).

- **Domain**: ``ai.onnx``
- **Since version**: 6

Ceil takes one input data (Tensor ) and produces one output data
(Tensor ) where the ceil is, y = ceil(x), is applied to
the tensor elementwise.

**Inputs**

- **X** (*T*): Input tensor

**Outputs**

- **Y** (*T*): Output tensor

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
