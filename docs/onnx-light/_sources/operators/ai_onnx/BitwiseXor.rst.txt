.. _op_ai_onnx_BitwiseXor:

BitwiseXor
==========

- **Domain**: ``ai.onnx``
- **Since version**: 18

Returns the tensor resulting from performing the bitwise ``BitwiseXor`` operation
elementwise on the input tensors ``A`` and ``B`` (with Numpy-style broadcasting support).

**Inputs**

- **A** (*T*): First input operand for the bitwise operator.
- **B** (*T*): Second input operand for the bitwise operator.

**Outputs**

- **C** (*T*): Result tensor.

**Type Constraints**

- **T**: Constrain input to integer tensors.
  Allowed types: tensor(int16), tensor(int32), tensor(int64), tensor(int8), tensor(uint16), tensor(uint32), tensor(uint64), tensor(uint8).

Examples
--------
