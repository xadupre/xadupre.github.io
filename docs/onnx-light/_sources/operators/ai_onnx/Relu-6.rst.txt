Relu - version 6
================

This page documents version **6** of operator **Relu**. See :doc:`Relu` for the latest version (since version 14).

- **Domain**: ``ai.onnx``
- **Since version**: 6

Relu takes one input data (Tensor ) and produces one output data
(Tensor ) where the rectified linear function, y = max(0, x), is applied to
the tensor elementwise.

**Inputs**

- **X** (*T*): Input tensor

**Outputs**

- **Y** (*T*): Output tensor

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
