Identity - version 13
=====================

This page documents version **13** of operator **Identity**. See :doc:`Identity` for the latest version (since version 25).

- **Domain**: ``ai.onnx``
- **Since version**: 13

Identity operator

**Inputs**

- **input** (*T*): Input tensor

**Outputs**

- **output** (*T*): Tensor to copy input into.

**Type Constraints**

- **T**: Constrain input and output types to all tensor types.
  Allowed types: tensor(bfloat16), tensor(bool), tensor(complex128), tensor(complex64), tensor(double), tensor(float), tensor(float16), tensor(int16), tensor(int32), tensor(int64), tensor(int8), tensor(string), tensor(uint16), tensor(uint32), tensor(uint64), tensor(uint8).
