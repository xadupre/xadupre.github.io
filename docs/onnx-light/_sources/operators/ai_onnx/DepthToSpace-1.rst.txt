DepthToSpace - version 1
========================

This page documents version **1** of operator **DepthToSpace**. See :doc:`DepthToSpace` for the latest version (since version 13).

- **Domain**: ``ai.onnx``
- **Since version**: 1

DepthToSpace rearranges (permutes) data from depth into blocks of spatial data.
This is the reverse transformation of SpaceToDepth. More specifically, this op outputs a copy of
the input tensor where values from the depth dimension are moved in spatial blocks to the height
and width dimensions.

**Inputs**

- **input** (*T*): Input tensor of [N,C,H,W], where N is the batch axis, C is the channel or depth, H is the height and W is the width.

**Outputs**

- **output** (*T*): Output tensor of [N, C/(blocksize \* blocksize), H \* blocksize, W \* blocksize].

**Attributes**

- **blocksize** (*int*): Blocks of [blocksize, blocksize] are moved.

**Type Constraints**

- **T**: Constrain input and output types to all tensor types.
  Allowed types: tensor(bool), tensor(complex128), tensor(complex64), tensor(double), tensor(float), tensor(float16), tensor(int16), tensor(int32), tensor(int64), tensor(int8), tensor(string), tensor(uint16), tensor(uint32), tensor(uint64), tensor(uint8).
