OptionalGetElement - version 18
===============================

This page documents version **18** of operator **OptionalGetElement**. See :doc:`OptionalGetElement` for the latest version (since version 28).

- **Domain**: ``ai.onnx``
- **Since version**: 18

If the input is a tensor or sequence type, it returns the input.
If the input is an optional type, it outputs the element in the input.
It is an error if the input is an empty optional-type (i.e. does not have an element) and the behavior is undefined in this case.

**Inputs**

- **input** (*O*): The optional input.

**Outputs**

- **output** (*V*): Output element in the optional input.
