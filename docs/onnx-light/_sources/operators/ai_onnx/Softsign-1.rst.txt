Softsign - version 1
====================

This page documents version **1** of operator **Softsign**. See :doc:`Softsign` for the latest version (since version 22).

- **Domain**: ``ai.onnx``
- **Since version**: 1

Calculates the softsign (x/(1+``|x|``)) of the given input tensor element-wise.

**Inputs**

- **input** (*T*): Input tensor

**Outputs**

- **output** (*T*): The softsign (x/(1+``|x|``)) values of the input tensor computed element-wise

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
