Cast - version 24
=================

This page documents version **24** of operator **Cast**. See :doc:`Cast` for the latest version (since version 28).

- **Domain**: ``ai.onnx``
- **Since version**: 24

The operator casts the elements of a given input tensor to a data type
specified by the 'to' argument and returns an output tensor of the same size in
the converted type. The 'to' argument must be one of the data types specified
in the 'DataType' enum field in the TensorProto message.
The onnx-light native runtime additionally supports complex64 and complex128
as an extension to ONNX Cast. Real-to-complex casts set the imaginary component
to zero. Complex-to-real casts discard it; complex precision casts preserve both
components. Complex casts involving strings, float8 or packed types are unsupported.
The standard ONNX schemas and full checker do not accept this extension.

**Inputs**

- **input** (*T1*): Input tensor to be cast.

**Outputs**

- **output** (*T2*): Output tensor with the same shape as input with type specified by the 'to' argument

**Attributes**

- **round_mode** (*string*): Rounding mode for conversion to float8e8m0. It only applies to casting to float8e8m0 and is ``up`` by default. ``up``: round to nearest value away from zero, ``down``: round to nearest value towards zero, ``nearest``: round to nearest value and ties round up.
- **saturate** (*int*): The parameter defines how the conversion behaves if an input value is out of range of the destination type. It only applies for float 8 conversion (float8e4m3fn, float8e4m3fnuz, float8e5m2, float8e5m2fnuz). It is true by default. All cases are fully described in two tables inserted in the operator description.
- **to** (*int*): The data type to which the elements of the input tensor are cast. Strictly must be one of the types from DataType enum in TensorProto.

**Type Constraints**

- **T1**: Constrain input types. Complex types are an onnx-light runtime extension.
  Allowed types: tensor(bfloat16), tensor(bool), tensor(complex128), tensor(complex64), tensor(double), tensor(float), tensor(float16), tensor(float4e2m1), tensor(float8e4m3fn), tensor(float8e4m3fnuz), tensor(float8e5m2), tensor(float8e5m2fnuz), tensor(float8e8m0), tensor(int16), tensor(int32), tensor(int4), tensor(int64), tensor(int8), tensor(string), tensor(uint16), tensor(uint32), tensor(uint4), tensor(uint64), tensor(uint8).
- **T2**: Constrain output types. Complex types are an onnx-light runtime extension.
  Allowed types: tensor(bfloat16), tensor(bool), tensor(complex128), tensor(complex64), tensor(double), tensor(float), tensor(float16), tensor(float4e2m1), tensor(float8e4m3fn), tensor(float8e4m3fnuz), tensor(float8e5m2), tensor(float8e5m2fnuz), tensor(float8e8m0), tensor(int16), tensor(int32), tensor(int4), tensor(int64), tensor(int8), tensor(string), tensor(uint16), tensor(uint32), tensor(uint4), tensor(uint64), tensor(uint8).
