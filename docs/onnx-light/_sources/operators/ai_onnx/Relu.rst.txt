Relu
====

- **Domain**: ``ai.onnx``
- **Since version**: 14

Relu takes one input data (Tensor ) and produces one output data
(Tensor ) where the rectified linear function, y = max(0, x), is applied to
the tensor elementwise.

**Inputs**

- **X** (*T*): Input tensor

**Outputs**

- **Y** (*T*): Output tensor

**Type Constraints**

- **T**: Constrain input and output types to signed numeric tensors.
  Allowed types: tensor(bfloat16), tensor(double), tensor(float), tensor(float16), tensor(int16), tensor(int32), tensor(int64), tensor(int8).
