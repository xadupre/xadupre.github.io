.. _op_ai_onnx_Exp:

Exp
===

- **Domain**: ``ai.onnx``
- **Since version**: 13

Computes the Exp value of the input tensor element-wise.

**Inputs**

- **input** (*T*): Input tensor

**Outputs**

- **output** (*T*): The exponential of the input tensor computed element-wise

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(bfloat16), tensor(double), tensor(float), tensor(float16).

--------

.. code-block:: text

    Inputs:
