IsNaN - version 13
==================

This page documents version **13** of operator **IsNaN**. See :doc:`IsNaN` for the latest version (since version 20).

- **Domain**: ``ai.onnx``
- **Since version**: 13

Returns which elements of the input are NaN.

**Inputs**

- **X** (*T1*): input

**Outputs**

- **Y** (*T2*): output

**Type Constraints**

  Allowed types: tensor(bfloat16), tensor(double), tensor(float), tensor(float16).
- **T2**: Constrain output types to boolean tensors.
  Allowed types: tensor(bool).
