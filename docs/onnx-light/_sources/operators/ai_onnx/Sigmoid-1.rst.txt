Sigmoid - version 1
===================

This page documents version **1** of operator **Sigmoid**. See :doc:`Sigmoid` for the latest version (since version 13).

- **Domain**: ``ai.onnx``
- **Since version**: 1

Sigmoid takes one input data (Tensor ) and produces one output data
(Tensor ) where the sigmoid function, y = 1 / (1 + exp(-x)), is applied
to the tensor element-wise.

**Inputs**

- **X** (*T*): Input tensor

**Outputs**

- **Y** (*T*): Output tensor

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
