.. _op_ai_onnx_Not:

Not
===

- **Domain**: ``ai.onnx``
- **Since version**: 1

Returns the negation of the input tensor element-wise.

**Inputs**

- **X** (*T*): Input tensor

**Outputs**

- **Y** (*T*): Output tensor

**Type Constraints**

- **T**: Constrain input/output to boolean tensors.
  Allowed types: tensor(bool).

Examples
--------

**test_cc_not**

.. code-block:: text

    Node:
      Not(x) -> (y)

.. code-block:: text

    Inputs:
      x: shape=(2, 2), dtype=bool
        [[ True, False],
         [ True, False]]

    Outputs:
      y: shape=(2, 2), dtype=bool
        [[False,  True],
         [False,  True]]

**test_not_2d**

.. code-block:: text

.. code-block:: text

    Inputs:

         [ True,  True,  True, False],
         [ True,  True, False,  True]]

    Outputs:

         [False, False, False,  True],
