Dropout - version 10
====================

This page documents version **10** of operator **Dropout**. See :doc:`Dropout` for the latest version (since version 22).

- **Domain**: ``ai.onnx``
- **Since version**: 10

**Inputs**

- **data** (*T*): The input data as Tensor.

**Outputs**

- **output** (*T*): The output.
- **mask** (*T1*): The output mask.

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
- **T1**: Constrain output mask types to boolean tensors.
  Allowed types: tensor(bool).
