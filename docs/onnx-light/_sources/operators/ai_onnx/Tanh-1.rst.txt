Tanh - version 1
================

This page documents version **1** of operator **Tanh**. See :doc:`Tanh` for the latest version (since version 13).

- **Domain**: ``ai.onnx``
- **Since version**: 1

Calculates the hyperbolic tangent of the given input tensor element-wise.

**Inputs**

- **input** (*T*): 1-D input tensor

**Outputs**

- **output** (*T*): The hyperbolic tangent values of the input tensor computed element-wise

**Type Constraints**

- **T**: Constrain input and output types to float tensors.
  Allowed types: tensor(double), tensor(float), tensor(float16).
