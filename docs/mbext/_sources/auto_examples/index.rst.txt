Examples gallery
================

These examples show how to use :func:`modelbuilder.builder.create_model` on
**tiny, randomly-initialised** models. They follow the same philosophy as the
fast test suite: everything runs offline, in seconds, with no weights downloaded
from the Hugging Face hub.
