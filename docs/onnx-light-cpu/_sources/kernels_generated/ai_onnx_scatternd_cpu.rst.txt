ScatterND (CPU)
===============

* Domain: ``ai.onnx``
* Device: ``CPU``
* Kernel: ``onnx_light_cpu::ScatterND``
* Supported types: ``FLOAT``, ``DOUBLE``, ``FLOAT16``, ``BFLOAT16``, ``INT8``, ``UINT8``, ``INT16``, ``UINT16``, ``INT32``, ``UINT32``, ``INT64``, ``UINT64``, ``BOOL``, ``FLOAT8E4M3FN``, ``FLOAT8E4M3FNUZ``, ``FLOAT8E5M2``, ``FLOAT8E5M2FNUZ``, ``FLOAT8E8M0``
* Opset bounds: since opset 11

Operator support
----------------

The standard ONNX schema and any standard shape inference come from onnx-light. No additional shape, peak-memory, fusion-pattern, or gradient implementation is registered by onnx-light-cpu for this operator.
