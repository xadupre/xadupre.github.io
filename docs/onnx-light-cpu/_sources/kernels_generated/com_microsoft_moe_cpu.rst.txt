LightOpSchema
~~~~~~~~~~~~~

**Version:** 1

ONNX Runtime CPU MoE: softmax router logits, select top-k experts and combine their outputs. FC1 and FC2 weights are expert-major, output-major.

**Inputs**

- **input** (``T``): Rank-2 (tokens, hidden) or rank-3 (batch, sequence, hidden).
- **router_probs** (``T``): Rank-2 (tokens, experts) logits, or probabilities when router_probs_are_logits=0.
- **fc1_experts_weights** (``T``): (experts, intermediate * fusion, hidden).
- **fc1_experts_bias** (``T``): Optional (experts, intermediate * fusion).
- **fc2_experts_weights** (``T``): (experts, hidden, intermediate).
- **fc2_experts_bias** (``T``): Optional (experts, hidden).
- **fc3_experts_weights** (``T``): Optional (experts, intermediate, hidden). Not supported by CPU execution.
- **fc3_experts_bias** (``T``): Optional (experts, intermediate). Not supported by CPU execution.

**Outputs**

- **output** (``T``): Same shape and type as input.

**Attributes**

- **activation_alpha** (``FLOAT``): SwiGLU sigmoid scale. (optional, default: ``1``)
- **activation_beta** (``FLOAT``): SwiGLU linear offset. (optional, default: ``0``)
- **activation_type** (``STRING``): relu, gelu, silu, identity, swiglu, relu2 or geglu. CPU execution does not support relu2 or geglu. (optional, default: ``relu``)
- **k** (``INT``): Number of selected experts. (optional, default: ``1``)
- **normalize_routing_weights** (``INT``): Renormalize selected softmax weights. (optional, default: ``0``)
- **router_probs_are_logits** (``INT``): CPU extension: apply Softmax to router input when 1 (default); consume supplied routing probabilities unchanged when 0. (optional, default: ``1``)
- **swiglu_fusion** (``INT``): Gated layout: 0 separate (SwiGLU only), 1 interleaved, 2 concatenated. CPU execution supports only interleaved SwiGLU. (optional, default: ``0``)
- **swiglu_limit** (``FLOAT``): Optional SwiGLU clamp limit. (optional)
- **topk_tie_break_low** (``INT``): CPU extension: select lower expert indices on equal routing weights when 1. Default 0 preserves higher-index tie selection. (optional, default: ``0``)
- **use_sparse_mixer** (``INT``): Sparse mixer requires k=2. CPU execution supports only zero. (optional, default: ``0``)

**Type constraints**

- **T**: Matching FLOAT, FLOAT16 or BFLOAT16 tensors. Allowed types: tensor(bfloat16), tensor(float), tensor(float16).
