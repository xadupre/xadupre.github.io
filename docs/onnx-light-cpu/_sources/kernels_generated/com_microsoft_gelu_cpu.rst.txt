LightOpSchema
~~~~~~~~~~~~~

**Version:** 1

ONNX Runtime contrib Gelu: Y = 0.5 * X * (1 + erf(X / sqrt(2))). No attributes.

**Inputs**

- **X** (``T``): Input tensor of any rank.

**Outputs**

- **Y** (``T``): Output with the same shape and type as X.

**Type constraints**

- **T**: Floating-point tensors. Allowed types: tensor(bfloat16), tensor(double), tensor(float), tensor(float16).
