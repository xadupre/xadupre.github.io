LightOpSchema
~~~~~~~~~~~~~

**Version:** 1

Restricted compatibility subset of ONNX Runtime MatMulNBits. The CPU implementation accepts matching FLOAT, FLOAT16, or BFLOAT16 activations, scales, optional bias, and output; UINT8 packed INT2, INT4, or INT8 weights; block_size=32, weight_prepacked=0, and accuracy_level 0 or 4. zero_points and g_idx retain their upstream input slots but must not be supplied. Packed B has shape (N, ceil(K / 32), 4 * bits), scales has shape (N, ceil(K / 32)) or its flattened equivalent, and bias has shape (N).

**Inputs**

- **A** (``T1``): FLOAT, FLOAT16, or BFLOAT16 tensor of rank at least one ending in K.
- **B** (``T2``): UINT8 packed weights with shape (N, ceil(K / 32), 4 * bits).
- **scales** (``T1``): Block scales with shape (N, ceil(K / 32)) or its flattened equivalent.
- **zero_points** (``T3``): Unsupported optional upstream zero-point slot; must be omitted.
- **g_idx** (``T4``): Unsupported deprecated upstream group-index slot; must be omitted.
- **bias** (``T1``): Optional bias with shape (N) and A's type.

**Outputs**

- **Y** (``T1``): Output with A's type, leading dimensions, and final dimension N.

**Attributes**

- **K** (``INT``): Positive input feature count. (required)
- **N** (``INT``): Positive output feature count. (required)
- **accuracy_level** (``INT``): Accuracy level; 0 and 4 are supported. (optional, default: ``0``)
- **bits** (``INT``): Quantized weight bit width; 2, 4, and 8 are supported. (optional, default: ``4``)
- **block_size** (``INT``): Quantization block size; only 32 is supported. (required)
- **weight_prepacked** (``INT``): Prepacked-weight flag; only 0 is supported. (optional, default: ``0``)

**Type constraints**

- **T1**: Constrain A, scales, bias, and Y to matching non-double floating-point tensors. Allowed types: tensor(bfloat16), tensor(float), tensor(float16).
- **T2**: Constrain packed B to UINT8. Allowed types: tensor(uint8).
- **T3**: Retain the upstream zero_points type slot; this subset rejects a supplied value. Allowed types: tensor(uint8).
- **T4**: Retain the upstream g_idx type slot; this subset rejects a supplied value. Allowed types: tensor(int32).
