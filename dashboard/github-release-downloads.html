GitHub release downloads — ONNX projects

Public xadupre onnx-light, onnx-light-* and yet-another-* repositories, plus ONNX projects linked from the home page and Microsoft's onnxruntime-genai and onnxruntime-extensions. Counts include uploaded files from all published releases, including prereleases. GitHub-generated source archives, clones and PyPI downloads are excluded.

Collected daily in UTC. History starts at the first collection, not the release date. Changes are net counter differences, not unique users: deleting or replacing assets can reduce totals. A dash means the baseline day was not collected. Repositories without release assets have a zero total. Each project has its own graph, showing all files combined by default. Expand the file list and check filenames to add their individual cumulative curves. File history starts when per-file collection is enabled; older total-only samples remain available but are not inferred as per-file counts.
