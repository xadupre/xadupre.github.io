onnx-light — package size over time

⚠ The results displayed on this page are indicative and experimental.

Lines of Python and C++ source code over time

Lines are counted directly from the onnx-light checkout (build artefacts, virtual environments and vendored code are excluded). Solid lines show source code lines, dashed lines show comment lines.

Wheel size over time

The full wheel and the reduced wheel (built with ONNX_LIGHT_BUILD_KERNELS=OFF, shown as a (reduced) line) are plotted together. Drag to pan, mouse wheel or pinch to zoom. Double-click to reset.

Binary size over time

Drag to pan, mouse wheel or pinch to zoom. Double-click to reset. Binaries prefixed with _onnxpy use cross markers; others use circle markers. Binaries that are no longer produced by the latest build are omitted.

Binary size over time (excluding lib, backend and kernel)

Same data as above but the largest lib, backend and kernel binaries are excluded so the smaller ones are readable. Drag to pan, mouse wheel or pinch to zoom. Double-click to reset.
