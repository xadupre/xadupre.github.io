yet-another-onnx-builder — model export discrepancies

For a fixed set of HuggingFace model ids, this page reports whether python -m yobx validate still exports the model to ONNX without numerical discrepancies, for two exporter configurations: yobx with --opt default and dynamo with --opt ir. All runs use --dtype float16 --device cpu. The snapshot below is regenerated by scripts/record_yobx_model_validate.py. Each cell also shows the last date the configuration was known to work, so that regressions are easy to spot.

⚠ The results displayed on this page are indicative and experimental.
