onnx-light-cpu — Gemm dtype benchmark

Processing time of the onnx‑light‑cpu SIMD-accelerated Gemm kernel for its three supported element types — float32, float16 and bfloat16 — on one representative shape per internal code path (single‑tile, K‑chunked, multi‑panel and skinny‑M/wide‑N). onnxruntime is shown for float32/float16 (its CPU provider has no bfloat16 Gemm), and onnx‑light's own un-accelerated reference kernel is shown for float32 on the two lighter shapes as a baseline. Every measurement runs 3 warm-up calls (not timed) and keeps the median of 10 timed repetitions. speed-up (cpu) = onnxruntime float32 / onnx‑light‑cpu float32: values > 1 mean onnx‑light‑cpu is faster than onnxruntime.

⚠ The results displayed on this page are indicative and experimental.
